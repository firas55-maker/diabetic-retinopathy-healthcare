💡 TIPS & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

If backend won't start:
  → Check: python -m uvicorn backend.main:app --reload
  → Verify: Port 8000 is not in use
  → Check: .env file has GEMINI_API_KEY set (can be placeholder)

If chat shows "Configuration Issue":
  → Check: .env has actual API key (not placeholder)
  → Restart: Backend server
  → Verify: python check_config.py shows ✅

If animations are choppy:
  → Clear browser cache: Ctrl+Shift+Delete
  → Hard refresh: Ctrl+Shift+R
  → Check: Console for JavaScript errors (F12)

If knowledge base doesn't load:
  → Verify: backend/knowledge/diabetes_education.txt exists
  → Check: Backend console for warnings
  → Chat still works but with less context
