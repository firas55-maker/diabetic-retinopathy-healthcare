⚠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ "Please set your actual GEMINI_API_KEY in .env"
   → Your .env still has the placeholder value
   → Replace with your actual API key
   → Restart backend server
   → Run: python check_config.py

❌ "Failed to connect to Gemini API"
   → Check internet connection
   → Verify API key at https://aistudio.google.com/app/apikey
   → Ensure API key hasn't been revoked
   → Wait a few seconds and retry (quota limits)

❌ Chat widget not showing on Patient Portal
   → Clear browser cache (Ctrl+Shift+Delete)
   → Restart frontend dev server
   → Check browser console for errors (F12)

❌ Knowledge base not loading
   → File exists at: backend/knowledge/diabetes_education.txt
   → Chat still works but with less context
   → Check console: "Warning: Could not load knowledge base"

❌ Backend won't start
   → Verify Python 3.8+ is installed
   → Ensure virtual environment is activated
   → Check for port 8000 conflicts: netstat -ano | findstr :8000
   → Kill process on 8000 if needed
