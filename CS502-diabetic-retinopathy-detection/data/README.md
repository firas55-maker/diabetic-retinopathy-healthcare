# Dataset

This project uses a unified Diabetic Retinopathy dataset created by combining retinal images from:

- EyePACS
- APTOS
- APTOS (Gaussian Filtered)
- Messidor

The unified dataset contains a total of **92,501 JPG images**.

## Dataset Split

The images were randomly divided into:

- **80% — Training**
- **10% — Validation**
- **10% — Test**

## Dataset Location

The complete dataset is approximately 3 GB and is not included directly in this Git repository.

Place the dataset inside:

CS502-diabetic-retinopathy-detection/data/

The dataset should be obtained from its original/public source.

## Reproducibility

This repository contains the source code, notebooks, preprocessing procedures, model architectures, training code, and evaluation code required to reproduce the project.

After obtaining the dataset, place it in the data/ directory before running the relevant notebooks or scripts.
