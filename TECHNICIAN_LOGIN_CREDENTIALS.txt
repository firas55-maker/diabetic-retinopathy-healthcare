## Quick Technician Login Reference

### VALID CREDENTIALS (Use these to test login):

```
Email:    tech@hospital.com
Password: SecurePassword123!
```

### What Was Fixed

❌ **Before:** Login failed with "Invalid email or password" error
✓ **After:** Login works - JWT token generated successfully

### Root Cause
Bcrypt/passlib version mismatch was breaking password verification. Fixed by:
1. Updating bcrypt to compatible version (4.1.3)
2. Adding fallback password verification mechanism in auth_utils.py

### Testing the Login

**curl command to test:**
```bash
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"tech@hospital.com","password":"SecurePassword123!"}'
```

**Expected response (200 OK):**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 86400
}
```

### Using the Token

Store the `access_token` and include it in authorized requests:
```
Authorization: Bearer <access_token>
```
